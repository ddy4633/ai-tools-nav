## 🔴 P0 级别问题（必须修复）

### 1. Hero 区域移动端适配问题
**来源**: GLM-5.0 + MiniMax
**问题**: 移动端留白不足，文字过大
**影响**: 影响首屏体验
**解决方案**:
```css
/* 修改 py-20 md:py-28 为 */
py-24 md:py-32

/* 移动端标题字号减小 */
text-3xl md:text-5xl
```

### 2. 图片未使用 next/image
**来源**: GLM-5.0 + Kimi-2.5
**问题**: 影响性能和 SEO
**影响**: 页面加载慢，Lighthouse 评分低
**解决方案**: 全局替换 img 为 next/Image

### 3. Supabase 错误处理缺失
**来源**: Kimi-2.5
**问题**: 数据获取失败时无降级方案
**影响**: 可能导致白屏
**解决方案**: 添加 try-catch 和 ErrorBoundary

### 4. 工具详情页内容单一
**来源**: GLM-5.0
**问题**: 只有名称、描述、定价
**影响**: 信息不足，用户决策困难
**解决方案**: 添加截图、功能列表、使用场景

### 5. 搜索无自动补全
**来源**: MiniMax
**问题**: 用户不知道能搜什么
**影响**: 搜索转化率低
**解决方案**: 添加搜索建议组件

### 6. 缺少面包屑导航
**来源**: MiniMax
**问题**: 用户容易迷失
**影响**: 导航体验差
**解决方案**: 添加 Breadcrumb 组件

### 7. 筛选器移动端太小
**来源**: MiniMax
**问题**: 触摸区域不足 44px
**影响**: 移动端难以操作
**解决方案**: 增大按钮尺寸

### 8. 空状态体验差
**来源**: GLM-5.0 + MiniMax
**问题**: 只有简单文字
**影响**: 用户不知道下一步做什么
**解决方案**: 添加图标、引导、推荐

### 9. 无防抖搜索
**来源**: Kimi-2.5
**问题**: 每次输入都触发搜索
**影响**: 性能问题
**解决方案**: 添加 useDebounce hook

### 10. 缺少骨架屏
**来源**: GLM-5.0 + Kimi-2.5
**问题**: 数据加载时无反馈
**影响**: 用户以为页面卡死
**解决方案**: 已创建 skeleton.tsx，应用到 loading 状态

## 技术方案选型

### 图片优化
```tsx
import Image from 'next/image';

<Image
  src={tool.image}
  alt={`${tool.name} 截图`}
  width={800}
  height={400}
  placeholder="blur"
  blurDataURL="data:image/jpeg;base64,..."
/>
```

### 搜索防抖
```tsx
import { useDebounce } from 'use-debounce';

const [debouncedSearch] = useDebounce(searchQuery, 300);
```

### 错误边界
```tsx
class ErrorBoundary extends React.Component {
  componentDidCatch(error, errorInfo) {
    // 错误处理
  }
  render() {
    if (this.state.hasError) {
      return <ErrorFallback />;
    }
    return this.props.children;
  }
}
```

### 面包屑
```tsx
const breadcrumbs = [
  { label: '首页', href: '/' },
  { label: '工具', href: '/tools' },
  { label: tool.name, href: `/tools/${tool.id}` },
];
```
