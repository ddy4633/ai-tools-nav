### 1. 技术实现

#### 组件结构
```typescript
// components/ui/ToolCardEnhanced.tsx
interface ToolCardEnhancedProps {

}

// 使用framer-motion的useMotionValue和useTransform
// 实现鼠标位置跟踪和3D倾斜效果
```

#### 状态管理
- 不需要全局状态
- 使用useMotionValue跟踪鼠标位置

#### 数据流
```
MouseEvent → useMotionValue → useTransform → motion.div style
```

#### 类型定义

## 任务2: 工具Logo墙组件

### 1. 技术实现

#### 组件结构
```typescript
// components/home/LogoWall.tsx
interface LogoWallProps {
  tools: Tool[]; // 取前12-16个
  speed?: number; // 滚动速度
  direction?: 'left' | 'right';
}

// 子组件
// - LogoItem: 单个Logo展示
// - LogoTrack: 无限滚动轨道
```

#### 状态管理
- 无需React状态
- 纯CSS动画实现无限滚动

#### 数据流
```
Tools Data → Filter (has logo) → Slice (16 items) → Render → CSS Animation
```

#### 类型定义
```typescript
interface LogoItemProps {
  name: string;
  logo: string;
  url: string;
}

interface LogoWallProps {
  tools: Pick<Tool, 'name' | 'logo' | 'url'>[];
  animationDuration?: number; // 秒
}
```

#### 依赖
- 无需新增依赖

---

### 2. 视觉设计

#### 色彩方案
```css
/* Logo墙背景 */
--logo-wall-bg: linear-gradient(
  90deg,
```

#### 暗色模式

### 3. 交互体验

#### 加载状态
- 组件级Skeleton: 灰色方块占位

#### 空状态
- 无Logo时隐藏组件

#### 错误状态
- 图片加载失败: 显示首字母占位

#### 动效规范
```css
/* 无限滚动动画 */
@keyframes scroll-left {
  from { transform: translateX(0); }
  to { transform: translateX(-50%); }
}

.logo-track {
  animation: scroll-left 30s linear infinite;
}

/* 悬停暂停 */
.logo-wall:hover .logo-track {
  animation-play-state: paused;
}

/* Logo悬停 */
.logo-item {
  transition: all 0.3s ease;
  filter: grayscale(100%) opacity(0.6);
}

.logo-item:hover {
  filter: grayscale(0%) opacity(1);
  transform: scale(1.1);
}
```

#### 可访问性
- `prefers-reduced-motion`: 禁用滚动，静态展示
- 每个Logo添加alt文本
- 链接可键盘访问
