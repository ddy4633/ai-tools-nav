## 5. 综合设计趋势总结

### 5.1 共同特点
1. **极简主义**: 大量留白，内容聚焦
2. **深色主题支持**: 几乎都原生支持暗色模式
3. **产品优先**: 首屏直接展示产品预览
4. **动效增强**: 微妙但精致的动画效果
5. **字体层次**: 清晰的大标题+副标题结构

### 5.2 色彩趋势
| 网站 | 主色调 | 暗色背景 | 强调色 |
|------|--------|----------|--------|
| Linear | #08090a | ✓ | 紫色/蓝色 |
| Shadcn | #ffffff | #09090b | 蓝色 |
| Vercel | #FAFAFA | ✓ | 蓝色 |
| Cursor | #f7f7f4 | #14120b | 琥珀色 |

### 5.3 布局模式
1. **Hero区域**: 大标题 + 副标题 + CTA + 预览图
2. **Logo墙**: 客户/合作伙伴Logo展示
3. **特性网格**: 2-4列功能特性展示
4. **Footer**: 简洁的链接分组

### 5.4 动效模式
1. **入场动画**: 元素从下往上淡入
2. **悬停反馈**: 缩放、阴影、颜色变化
3. **平滑过渡**: 主题切换、页面切换
4. **微交互**: 按钮点击、复制反馈
